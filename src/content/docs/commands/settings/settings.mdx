The new `/settings` command is the one-stop shop for both viewing and
controlling all server settings. Anyone with `Manage Server` permissions can
access this command to change settings for Archivist, so be careful what roles
and people you give that permission to.

Settings have been broken into the five categories below. Visit each page to
learn about the settings available in that category.
