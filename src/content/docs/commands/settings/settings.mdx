Use the `/settings` command to view and change how Archivist works in your
server. The command opens an interactive settings panel. You need the Discord
`Manage Server` permission to use it and change settings.

The panel groups settings into five pages. These settings control what
information Archivist shows for Archive of Our Own (AO3) works, chapters,
series, and user profiles, as well as general server preferences.

<ImageCarousel folder="settings" label="Settings examples" />

## Navigate the settings panel

- **Choose a page:** Use the menu below the panel to open General, Work,
  Chapter, Series, or User Profile.
- **Move between pages:** Select **Previous** or **Next** to move to the page
  before or after the one you are viewing.
- **Select a section:** Select a section button, such as **Stats**, **Tags**,
  or **Inactivity**, to open a form for those settings. The available
  buttons depend on the page.
- **Restore defaults:** Use the red reset button to restore the current page's
  settings to their default values.
