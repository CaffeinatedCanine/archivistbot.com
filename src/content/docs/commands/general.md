Archivist’s general commands help users learn about the bot, invite it to a
server, check that it is online, and find support links. These commands are
useful for both new users and server admins who want to share the bot with
others.

## About the general commands

The general command category includes the commands that help users understand
and use Archivist without needing to look elsewhere. These commands are simple,
quick, and designed for everyday Discord use.

- `/about` — show bot information, uptime, server count, and links
- `/help` — list available commands and command categories
- `/invite` — get an invite link to add Archivist to another server
- `/ping` — check the bot’s response time
- `/support` — find ways to support the project and join the community
- `/vote` — open voting links on bot lists

## About

Use `/about` to learn more about Archivist itself. This command shows:

- the bot version
- uptime
- total server count
- total user count
- launch date
- important links, including the website, support server, and privacy policy

This command is helpful if you want to check whether the bot is active or if you
need official links for the project.

## Help

Use `/help` to view a list of commands and get a quick overview of what
Archivist can do. The help command groups commands by category so it is easier
to browse the bot’s available features.

This command is especially helpful for new users who are still learning how to
work with the bot.

## Invite

Use `/invite` to generate an invite link for Archivist. This lets you add the
bot to a Discord server you manage.

If you are running a fanfiction or AO3-focused community, this is the easiest
way to bring Archivist into your server.

## Ping

Use `/ping` to check whether Archivist is responding normally. The command
measures the round-trip delay between your Discord interaction and the bot’s
response.

This is a quick health check and is useful when troubleshooting connection or
response issues.

## Support

Use `/support` to find ways to help the project grow. This command includes
links for:

- the support server
- voting and bot-list pages
- donation support
- spreading awareness about the bot

This command is designed for users who want to help without needing any special
permissions or technical setup.

## Vote

Use `/vote` to open voting pages for Archivist on bot listing sites. Voting
helps increase discoverability and support bot growth.

The command includes links to:

- top.gg
- Discord Bot List

Voting is free and helps the project reach more users.
